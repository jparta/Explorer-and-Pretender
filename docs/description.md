# Description

Two LLMs interact with each other. One is the Explorer, the other Pretender.

The Explorer is given very little to go by. It only knows that the goal is to find the Secret. The Pretender pretends to be a terminal (or possibly some other interface). The Explorer interacts with the Pretender in search of the Secret.

The interaction between these two LLMs makes up a Session. There are N Sessions in progress at any one time. Sessions may be viewed live on a website. A Session ends when the Secret is sounded out or the Session has run its course.

Website visitors may not interact with the exhibit. This is to keep LLM costs down.
